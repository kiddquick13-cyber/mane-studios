# MANE STUDIOS

Free streaming site for MANE STUDIOS series, movies and hometown stories.

- Live site: https://kiddquick13-cyber.github.io/mane-studios/
- To add or change a show, episode or movie, edit `js/catalog.js` (steps in `HOW-TO-ADD-A-VIDEO.txt`).
- Videos are stored in Cloudflare R2, not in this repository.
