MANE STUDIOS site: how to add a video
=====================================

Everything on the site is listed in one file:  js/catalog.js
You never need to touch the other files.

1. Shrink and name the video
   Big CapCut exports stream badly. Shrink them first (ask Claude).
   Use names with no spaces, like  tosl-s2e01.mp4

2. Upload it to Cloudflare
   Cloudflare > R2 Object Storage > manestudiosvideos > Upload.
   Its link is your storage address plus the file name:
     https://pub-aaebe547980947bf937593585efd745f.r2.dev/tosl-s2e01.mp4

3. Put the link in catalog.js (on GitHub)
   Open kiddquick13-cyber/mane-studios > js > catalog.js > the pencil (Edit).
   Each episode is one line:
     { title: "Episode 1", length: "3:00", video: "PASTE THE LINK HERE" },
   Keep the comma at the end of every line except the last one in a season.
   Click "Commit changes". The site updates in about a minute.

4. Adding a new season
   Copy the whole Season 1 block, paste it after it with a comma between
   them, rename it "Season 2", and change the episodes and links.

5. Posters
   Put a poster image in the media folder and point to it in catalog.js:
     poster: "media/your-poster.jpg"     (tall, 2:3)
     backdrop: "media/your-banner.jpg"   (wide, 16:9)

6. Ratings
   "TV-MA" titles ask viewers to confirm they're 18 or older before playing.
